# متابعة المبيعات والتحصيل

تطبيق ويب لمتابعة مبيعات وتحصيل المناديب، مبني بـ React + Vite، ويستخدم Firebase Realtime Database كقاعدة بيانات سحابية بحيث تتزامن البيانات بين كل الأجهزة.

## 1. إعداد قاعدة البيانات (مرة واحدة فقط)

1. اذهب إلى [console.firebase.google.com](https://console.firebase.google.com) وسجّل الدخول بحساب Google.
2. اضغط **Add project** وأنشئ مشروعًا جديدًا (يمكن تعطيل Google Analytics، غير ضروري هنا).
3. من القائمة الجانبية اختر **Build → Realtime Database**، ثم اضغط **Create Database**.
   - اختر أقرب موقع خادم لكم.
   - عند سؤالك عن قواعد الأمان (Security rules)، اختر **Start in test mode** مبدئيًا.
4. بعد الإنشاء، عدّل القواعد (تبويب **Rules** أعلى صفحة قاعدة البيانات) إلى:

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

ثم اضغط **Publish**. (ملاحظة: هذا يسمح بالقراءة/الكتابة لأي شخص يعرف رابط القاعدة — مناسب هنا لأن التطبيق نفسه لديه نظام تسجيل دخول خاص به.)

5. من أعلى صفحة Realtime Database انسخ الرابط الظاهر، شكله مثل:
   `https://your-project-id-default-rtdb.firebaseio.com`

## 2. ربط الكود بالمشروع

افتح الملف `src/App.jsx` وعدّل هذا السطر بالقيمة الحقيقية:

```js
const FIREBASE_DB_URL = "https://your-project-id-default-rtdb.firebaseio.com";
```

## 3. التشغيل محليًا (اختياري، للتجربة على جهازك)

```bash
npm install
npm run dev
```

سيفتح التطبيق على `http://localhost:5173`.

## 4. النشر على Vercel (لكي يعمل من أي جهاز)

1. ارفع هذا المجلد كمستودع (repository) على GitHub.
2. أنشئ حسابًا مجانيًا على [vercel.com](https://vercel.com) وسجّل الدخول بحساب GitHub.
3. اضغط **Add New Project**، واختر هذا المستودع.
4. Vercel يكتشف تلقائيًا أنه مشروع Vite، فقط اضغط **Deploy**.
5. بعد دقيقة ستحصل على رابط دائم مثل `https://sales-tracker-app.vercel.app` — هذا هو الرابط الذي يستخدمه الجميع من أي جهاز.

## ملاحظات

- كلمة مرور الإدارة الافتراضية عند أول تشغيل: `admin123` — غيّرها فورًا من "الإعدادات وواتساب" داخل لوحة الإدارة.
- كل عمليات الحفظ (المناديب، التقارير، العملاء، الأهداف...) تُخزَّن تحت مسار `kvstore/` في قاعدة بيانات Firebase، لذا التزامن يعمل بمجرد أن يفتح الجميع نفس رابط الموقع المنشور.
- لمشاهدة البيانات مباشرة، افتح تبويب **Data** داخل Realtime Database من لوحة تحكم Firebase.
- قواعد الأمان المفتوحة (`true, true`) مناسبة لأداة داخلية بحجم فريق مبيعات صغير؛ إذا رغبتم بحماية إضافية لاحقًا يمكن تقييدها بمفتاح سري بسيط.
